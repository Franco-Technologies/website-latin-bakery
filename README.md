# Latin Bakery Willard

A modern, responsive web application for **Latin Bakery Willard**, a family-owned bakery dedicated to bringing the authentic flavors of Latin American baking to the community.

## 🥐 Features

- **Interactive Menu**: Browse through a curated selection of fresh breads, pastries, and traditional Latin treats.
- **Location & Hours**: Easily find our Willard location with integrated Google Maps directions and up-to-date operating hours.
- **Newsletter Subscription**: Integrated with Square to keep our customers informed about fresh batches and exclusive weekend offers.
- **Responsive Design**: Optimized for all devices, from mobile phones to desktop computers.
- **Smooth Animations**: Powered by `motion` for a polished and engaging user experience.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) & Material Symbols
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:3000`.

## 📦 Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs TypeScript type checking.
- `npm run preview`: Previews the production build locally.
